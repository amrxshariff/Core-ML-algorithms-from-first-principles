| Gradient descent | Gradient Descent from first principles: Started by writing functions for quadratic and quadratic_grad, Noted analytical minimum to be able to assist it when choosing a learning rate. Proceeded to define function which returned the final point of the gradient + full history of positions + convergence stage applied to both quadratic and Rosenbrock. Ran both functions from a standard point (0.5,0.5), confirming it reached minimum on both. Convergence limit was set to the final point being within 1e-6 of the known minimum. Divergence threshold was then computed following the fact that learning rate must not exceed 2/max_eigenvalue computed from the hessian of both functions. Plots for gradient descent on both functions and log-loss / step count for 5 different learning rates were then saved with the contours and divergence thresholds incorporated respectively.<br><br>Findings - Hessian computed for simple quadratic and more complex Rosenbrock functions which enabled finding the maximum eigenvalue to compute the divergence threshold. Divergence threshold - learning rate / step size must be smaller than 2/ max eigenvalue of the function to ensure stability, otherwise gradient descent will not converge. Tests computed for learning rates slightly over and under the learning rate threshold for divergence were carried out and the expected convergence and divergence of gradient descent was observed through the figures: "loss_trajectory_[name of function]". |
| k-NN and distance metrics | K-NN from first principles: started by creating a 2D synthetic dataset with three classes and 2 features. Split the dataset into training and testing with a fixed random seed for reproducible outputs. Wrote individual functions for computing the euclidean, manhattan and cosine similarity distances which processed an individual query point and the entire training matrix. Each row was vectorised and applied to a custom KNN model which didn't import from sklearn libraries. Votes were implemented with numpy.argpartition rather than a full sort. Tie breaking rule adopted was just the default of argmax naturally returning the first index it comes across when there is a tie. To verify the custom KNN model, a test was conducted against the same data, same n_neighbours, and same metric, ensuring that predictions were equal to KNeighborsCLassifier. Additionally, distance functions were tested to be within 1e-10 of scipy distances and timing benchmarks were carried out for the difference between the custom model and a for loop that iterated through the entire dataset. Plots for the decsion boundary under the euclidean, manhattan, and cosine distances, under and overfitting when experimenting with k between 1 and 25 - larger cluster standard deviation implemented to force a larger scatter of points, figure showing what happens when features are scaled by a large number without standardisation. <br><br> Findings - assessing K-NN in higher dimensions. Function written to generate n unifrom random points in d dimensions with spacing at 40 different points to view progressive behaviour changes of dimensionality of distance ratio between the nearest and farthest neighbours. For every d in a sweep from the 2 to 1000 dimensions, the ratio of the nearest and farthest distance was computed and averaged over many different query points with respect to a main dataset. As the dimensionality scales up on the logarithmic axis, ratio smoothly climbs to 1 which suggests that the distance to a point's nearest neighbour becomes indistinguishable from the distance to it's farthest neighbourTakeaway, K-NN applied to higher dimensions makes the predictions obsolete and forces the model to guess a particular class rather than consider the votes for each class. When the ratio of nearest to farthest neighbours converges to 1, death of locality occurs - when every point in the dataset is roughly equidistant from query point, neighbourhood is no longer local and k nearest neighbours are no longer closer to the query than random selection of points across the entire dataset, and degenerate voting - since neighbours are effectively randomised due to distance concentration, majority vote no longer has it's discriminative power and so the model stops learning a decision boundary and resorts to reflecting the global class distribution (guessing) which plummets accuracy. ANN (approcimate nearest neighbours) is a solution to the incapability of KNN in higher dimensions. Threshold of 0.9 was selected as any additional data point afterwards just point to the same concensus that higher dimensions make the K-NN model inadequate. It is worth noting that the threshold would shift right as d grows larger and so relationship could be measured at values of 100, 1000, and 10000 to produce a well asserted cutoff.|
